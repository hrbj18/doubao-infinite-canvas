# Canvas Studio 0.2.12

豆包 / Dola 的 Windows 本地视频画布与 MCP 工作台。使用新源码实现，安装包和下载插件仅作为行为参考。

## 源码仓库

仓库包含应用源码、自动化测试、依赖锁定文件和使用文档。依赖、打包产物、本地账号数据、私人素材、验收截图与记录、一次性账号调试脚本不随源码发布。下文提到的 `creative/`、`validation/` 为本地开发记录目录。

首次从 GitHub 克隆后，在项目目录执行 `npm ci` 安装依赖，再运行 `npm start`。视频抽帧与拼接还需要在 PATH 中配置 `ffmpeg` 和 `ffprobe`。默认示例图来自本地开发素材；其他电脑首次启动时需自行导入图片。

## 启动

双击 `启动画布.cmd`，或直接运行 `dist/CanvasStudio-win32-x64/CanvasStudio.exe`。复制桌面版时需要复制整个 `CanvasStudio-win32-x64` 文件夹。

开发命令：

```powershell
npm install
npm start
npm run preview
npm run check
npm test
npm run package
```

桌面数据在 `%APPDATA%\CanvasStudio`；浏览器预览在项目的 `data-preview`，两者独立。抽帧调用系统 `ffmpeg` 和 `ffprobe`，当前开发电脑已安装；迁移时也需要这两个工具在 PATH 中。

## 当前实现与验证范围

- 项目持久保存、多项目切换、图片/生成/视频节点、平移缩放、连线和参考图角色。
- 首帧、指定秒数与精确最后可解码帧抽取，记录来源；通过真实 FFmpeg 像素对比验证。
- 视频节点一键准备同镜头续接、新分镜。继承平台/提示词/时长/比例；可加目标尾图。先检查和编辑再提交。
- 按选定顺序硬切拼接、保留原声；目标时长只裁成片末尾，容差一帧。素材不足则提示补充，原片完整保留。
- 豆包与 Dola 独立账号会话和平台账号池。支持用户手动登录，以及 Cookie 文本 / Cookie-Editor JSON / .txt/.json 文件导入；各账号独立会话。
- 生成、参数确认、结果查询和下载在隐藏的账号窗口中运行；界面只显示项目工作台。只有主动点击登录/打开账号页面才显示平台窗口。
- 国内账号默认自动管理额度，新任务默认 Seedance 2.0 Fast；15秒不再写死每天一次。已提交与预留独立记录，平台余额未知时逐任务核对，不显示虚假的剩余条数。Dola及兼容手动模式保留本地次数预算；北京时间零点仅切换项目记账日，不代表平台权益已恢复。
- 每账号 1 个进行中任务，最多 3 个；优选账号不可用时自动换同平台账号。
- 幂等提交、持久队列、跨日预留、重启后提交核实；不会因下载失败重新生成。
- 平台页面观察和下载源解析。平台源下载后先保持待验证，实际确认无可见水印才记为完成。不删除平台元数据。
- MCP 与画布共用同一工作台，HTTP 仅监听 127.0.0.1；调用需要本地会话授权。
- MCP 直接提交任务也回填图片与生成节点；续接、新分镜和导出均支持持久幂等操作。
- 首次素材授权声明在项目任务队列中展示，用户查看、明确同意后才推进平台弹窗。
- 本轮5秒验证模式：每平台最多2次，未知提交也占预算，禁止提交15秒。结束验证不会释放未知任务。
- 视频节点标明参考图生成、首帧/首尾输入或本地拼接来源；下载状态与动作效果验收分开。可查看指定首尾图与视频真实首尾帧的对照，播放后记录效果反馈；对照抽帧复用、反馈跨重启保存，不自动重生成。

## 首次使用

1. 在账号池添加账号并手动登录，或点击“导入 Cookie”粘贴内容 / 选择 .txt/.json 文件。现有账号点“更新 Cookie”可替换登录会话。
2. 点击检测登录，确认账号已就绪。
3. 打开预置小猫项目，编辑提示词并提交生成。
4. 在任务队列查看准备、生成、下载与待处理原因。
5. 对下载视频实际检查可见水印。若平台未返回可用源，保留任务并单独重试下载。

时长/比例留空使用平台当前设置；填写参数会先在页面选择并核对。国内15秒优先设置页面时长，兼容策略只作用于当前任务的视频能力请求；平台提议和下载实际时长均再次验证。不一致时保留结果等待反馈，不自动重生成。已有15秒原片通过实际时长验证；是否可生成更多条取决于账号当前额度。

选择视频节点后点“用尾帧继续同一镜头”或“创建新分镜”；顶部“导出成片”可选顺序、设定目标长度。Codex 生图及分镜调用流程见 [Agent 视频工作流](docs/agent-workflow.md)。生图由接入 MCP 的 Codex Agent 完成，应用接收生成图片，没有在应用内嵌入另一个大模型。

## 国内额度自动管理（0.2.9）

国内新任务模型留空时默认 Seedance 2.0 Fast。模型选择、参数确认和发送前均核对实际模型；指定其他模型时保留该选择，不静默降级。已有历史任务、模型和用量记录不改写。

国内账号可使用 quotaMode:auto（界面新增账号和Cookie导入默认使用）；已有账号由账号池配置切换。自动模式不再依赖手填每日条数，不再限制15秒每天一条。每账号一次准备或生成；未知提交先核实原任务。15秒被明确拒绝时暂停该模型/时长组合15分钟，仍可安排更短任务；这是本地重试间隔，不是平台重置规则。

登录账号空闲时每5分钟后台刷新官方套餐额度接口，也可点击同步平台额度。当前接口返回会员状态和时段用量百分比，没有免费视频的绝对余额与各时长消耗，因此界面显示未知，不把百分比换算成视频条数。同步只刷新页面读取权益，不生成视频、不购买套餐。

原任务参数确认/受理/拒绝反馈若明确给出消耗和剩余额度，记录相同模型、输入模式、分辨率与时长的成本参考。只在5分钟内且没有新的未核对提交时用该参考分配；不默认线性按秒计费。余额未知时逐任务核对平台，平台拒绝才切号；不是无限额度，也不能保证只消耗免费权益，账号有会员或额度包时以平台扣减顺序为准。实际每日总量、重置和失败退还尚无公开官方统一表，见 [核查记录](docs/doubao-fast-quota-research-20261010.md)。

Agent可用 studio_accounts(operation:quota,accountId)只读同步，或update设置quotaMode。旧manual模式保留本地预算兼容。Dola仍使用原有本地预算。

## Cookie 登录

导入支持 Cookie-Editor 数组 / {cookies:[…]} JSON、独立 name=value; … Cookie 行，以及夹有说明的 .txt 文件（提取唯一 Cookie 行，忽略卡密）。格式检查仅返回数量和到期信息。Cookie 域名必须属于所选平台，已过期登录 Cookie、冲突条目、非登录 Cookie 会被拒绝。

导入后不显示平台窗口，不发送消息或生成视频；账号先显示后台检测中，通过页面登录检测后才参与调度。新账号按设定本地预算建立，更新已有账号保留预算、今日用量和任务记录；生成、核实或下载中的账号不允许更新。幂等重试不重复建立账号，同一登录 Cookie 也不能重复建立账号而重复计算额度。

凭据在 %APPDATA%\CanvasStudio\credentials 下使用 Electron safeStorage / Windows 系统加密保存，不放进 state.json、项目导出、日志或 MCP 返回结果。无系统加密时拒绝导入，不回退到明文。平台刷新 Cookie 时更新加密副本；正常退出前保存最新会话，无到期信息的会话 Cookie 在重启后恢复，平台注销后不复活旧 Cookie。加密数据换 Windows 用户或设备可能无法读取，需要重新导入。

JSON 保留原 Cookie 到期时间，Cookie 文本不人为添加到期时间；显示有效期未知。Cookie 到期参考不保证平台保持登录，服务端注销、撤销或风控仍可能提前使会话失效。国内 Cookie 导入尚未用真实凭据实测；Dola 已使用用户授权本机文件通过登录、隐藏窗口和重启恢复验证，未生成视频。

Agent 调用 studio_cookie_login 只传 file 的绝对路径、platform 或 accountId、稳定 idempotencyKey；新账号还传 name 和 dailyLimit。不要把 Cookie 原文粘贴到聊天或工具参数。checking 返回后用 studio_accounts(list/probe) 查询登录结果。

## MCP

当前电脑已通过 `codex mcp add canvas_studio` 注册源码中的 `src/mcp.mjs`。运行工作台后，支持 MCP 的新连接可以调用以下工具：

| 工具 | 用途 |
| --- | --- |
| studio_status | 工作台与任务汇总 |
| studio_accounts | 用量、登录检测、预算、页面控件诊断 |
| studio_cookie_login | 从授权的本机 Cookie 文件新建/更新账号，后台检测登录 |
| studio_projects | 项目读取、创建、按版本保存 |
| studio_import_asset | 本地素材导入 |
| studio_generate | 按平台提交任务，必须传幂等键 |
| studio_tasks | 任务状态、作品观察和本地文件路径 |
| studio_video_review | 生成来源、实际首尾对照、动作效果反馈 |
| studio_continue_preparation | 页面已调整后继续准备 |
| studio_advance_task | 后台发送已准备内容、继续平台参数确认 |
| studio_confirm_submission | 根据平台证据核实已提交/未提交 |
| studio_attach_video | 将核实后的作品关联到任务 |
| studio_download | 单独重试下载、实际水印验证 |
| studio_extract_frame | 首/尾/指定时间抽帧 |
| studio_shot | 准备同镜头续接/新分镜与可选目标尾帧 |
| studio_merge | 顺序拼接、保留原声和目标定长导出 |
| studio_validation | 本轮5秒测试预算 |
| studio_cancel_task | 取消尚未提交的任务 |

提交示例：

```json
{
  "projectId": "项目ID",
  "platform": "doubao",
  "mode": "references",
  "prompt": "小猫轻轻眨眼，缓缓抬头和举剑，披风轻飘，固定镜头。",
  "refs": [{ "assetId": "素材ID", "role": "reference" }],
  "idempotencyKey": "kitten-motion-001"
}
```

原生首帧需要 `mode:first`，一张 `first`；首尾帧需要 `mode:first_last`，`first`、`last` 各一张。调度以本地预算判断，不保证平台接受；明确额度拒绝才释放并切号。未知提交保持核实状态，不能猜测未提交。

## 模块

Dola 成片自动下载：保持工作台运行、电脑唤醒和账号网络可用。优先实时监听作品；每20秒通过隐藏窗口重新读取原会话作为补充，核对完整提示词、提交时间和唯一新作品后立即下载。这个间隔是核对频率，网络加载和文件传输仍需要时间。任务卡显示平台作品消息时间、发现时间和下载完成时间；水印待确认的已保存文件会显示“已下载”。超时待核实的 Dola 原任务继续只读跟踪，不重新生成或占用新的生成预算。同账号下载期间先保存成片，再安排后续任务。

0.2.8 修复下载等待：点击原作品下载按钮后最多等待120秒启动，传输过程中只有连续45秒没有收到更多字节才判定停滞；持续传输可继续等待，总上限30分钟。任务卡显示接收进度和本次下载耗时。启动超时会关闭旧的隐藏窗口，避免延迟下载混入后续任务。

Dola 登录失效或出现区域限制时，暂停原作品下载并显示原因，保留作品、生成任务和额度记录。检测到有效登录后，只恢复被上述原因暂停的原作品下载；水印待处理的作品不会因此自动通过验证。更新 Cookie 应使用原账号的有效会话，才能继续访问原会话和作品；其他账号请单独添加。切换 IP 后仍需实际验证登录、原会话读取和原作品下载，不能仅凭网站能打开认定恢复。

首次素材声明需要本人明确同意。已同意的同一声明再次延迟出现时沿用该决定；声明文字改变时重新等待本人确认。并发恢复同一任务不会重复确认或发送。

国内原作品下载可通过本地 `account.options` 查询：`kind: { kind: "download_progress", taskId }`，仅检查文件头和本地进度。慢连接可由 Agent 调用 `kind: { kind: "resume_download", taskId }`：保留原下载，只对同一作品的缺失字节进行两路续传，严格核验 HTTP 206、字节区间和完整文件大小，再用 ffprobe 检验视频。结果沿用原任务完成入库，不提交生成或消耗新额度。目前此续传由 Agent/本地接口主动触发，尚未加入自动低速切换或界面按钮；不适用于 Dola。

- `src/core.cjs`：项目、素材、预算、调度和状态转换。画布与 MCP 调用同一个 module interface。
- `src/platform.cjs`：两平台的会话、页面准备、观察和下载 adapter。平台变化集中在这里处理。
- `src/account-cookies.cjs`：Cookie 格式校验、系统加密存储、会话恢复与后台登录检测。
- `src/quota.cjs`：分类额度与共享关系。
- `src/media.cjs`：视频信息、精确抽帧和定长拼接。
- `src/workflows.cjs`：续接、新分镜、幂等导出与画布回填。
- `src/video-review.cjs` 和 `ui/video-evidence.js`：实际首尾对照、来源判定与独立效果反馈。
- `src/platform-duration.cjs`：限定当前任务的15秒兼容策略。
- `src/server.cjs`：本地工作台接口和静态素材。
- `src/mcp.mjs`：stdio MCP，日志不写入 stdout。
- `ui/`：原生 HTML/CSS/JS 画布与管理界面。

备份时退出工作台，复制整个 `%APPDATA%\CanvasStudio`。登录状态可能随设备变化，需要重新登录；不要把该目录公开上传。
