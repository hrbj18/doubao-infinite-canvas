# 国内豆包 Seedance 2.0 Fast 免费额度核查

核查日期：2026-10-10（Asia/Shanghai）。范围是国内消费者豆包网页/APP，不是即梦积分、Dola、火山方舟 API 或第三方中转额度。本次仅检索公开资料；没有登录账号、读取 Cookie 或提交视频。

## 结论与证据边界

没有找到官方公开、可直接配置为统一常量的“国内豆包普通免费账号 Seedance 2.0 Fast 每日总量与各时长消耗表”。这表示本次检索不能证实，不表示平台一定没有该规则。

“每天两条 15 秒”“每天三条 7 秒”“全部免费账号额度完全一样”“15 秒每日只能一条”都不能从已找到的官方资料推出。模型支持某个时长，也不等于某个消费者账号在当天有足够额度。网页/APP实际可选时长及额度，需要读取当前账号的官方页面再确定。

## 被排除的线索

- 火山引擎 `/article/` 下的作者社区文章不是产品正式权益公告。例如 [会员定价文章](https://www.volcengine.com/article/2687110)、[虚拟人额度文章](https://www.volcengine.com/article/2690323)、[竞品对比文章](https://www.volcengine.com/article/2688680)来自开发者阿泽/云原生阿岚等署名作者，来源指向第三方，有互相不一致的额度说法。因此没有将这些数值作为项目配置依据。
- `seedance.tv`、`seedance2api.com` 等名字相似的网站，未被官方 Seed 页确认是消费者豆包额度说明。不能把其自有套餐、积分或 UTC 重置规则作为豆包规则。
- 方舟/BytePlus 官方资源包与模型 API 文档属于开发者计费。即使是一手官方资料，其适用产品仍不匹配本任务。

## 工程建议（项目设计建议，不是官方额度规则）

1. 默认请求模型可以设为 Fast，但在账号内核对它当前可选且可用；不可用时明确提示或排队，不静默切其他模型。
2. 保存账号、模型、模式、分辨率、时长对应的官方余额/成本快照，并记录来源、观测时间、有效性；不能把本地已提交次数当作官方余额。
3. 支持共享额度池，但共享关系只由官方页面/API字段或明确反馈确认，不能根据模型名猜测。
4. 调度使用有效余额减去本项目已预留量；预留、受理、失败、退还分开记账。外部 APP 使用和多端使用需要重新同步。
5. 未确认成本或余额时显示待核查，避免展示虚假的“可生成 N 条”；没有任务受理凭据时，不自动重发可能已经提交的请求。
6. 日界线只切换本地统计。平台未被重新核实之前，不自动把未知/耗尽余额恢复成满额。
7. 可用额度足够时再回答两条 15 秒或三条 7 秒的容量；若没有时长对应成本表，不能仅凭合计 30 秒或 21 秒判断。

## 补充：账号现场核查与项目落地（主代理）

以下来自本机已登录会话与项目验证，不属于上面的公开资料检索。

- 官方订阅额度摘要显示一个测试账号为普通账号（无有效订阅），没有视频免费余额和时长消耗表；另一个测试账号有有效标准套餐，接口显示一般能力的时段用量为 0%，仍没有免费 Fast 剩余次数。不能拿会员账号证明普通免费账号的容量。
- 已安装 0.2.9，两个现有国内账号已通过工作台 API 切换 `quotaMode: auto`；历史任务、登录会话、旧预算记录均保留。海外账号规则未变。
- 国内新任务未指定模型时使用 Seedance 2.0 Fast；提交前核对页面实际模型，不静默降级。删除未经证实的“15秒每天最多一条”限制。
- 国内自动规则不按本地提交次数假装耗尽账号，也不在本地日界线恢复虚构满额。记录平台用量快照，明确区分未知余额、套餐用量百分比和有来源的任务消耗反馈。
- 有新鲜、同模型和同参数的明确余额/消耗反馈时，扣除本项目预留量计算可用容量；未知时单账号逐任务核对。7秒、15秒的消耗分开观察，不假定线性或共享关系。余额反馈不是官方完整免费权益表。
- 某个参数组合被平台拒绝时，只对该组合设置本地15分钟冷却（这不是平台重置规则）；已受理或提交结果不明的任务先核对原任务，不轮询重发。
- 官方扣减顺序可能涉及已有创作额度包或会员权益。本次管理改进不能保证只消耗免费权益。
- 验证：101项测试通过；实机模型/参数复核未完成，后台平台页面未稳定显示编辑框与模型控件，登录状态显示待检测，不能据此断言 Cookie 已失效。此前观察过4–15秒时长滑杆，但本次没有确认实机成功选中7秒/15秒，也没有提交生成验证。
- 新增生成任务与额度消耗：0。原生成尝试记录仍为13条。账号窗口保持隐藏。账号池界面已验证显示0.2.9和自动额度卡片。

账号核查与参数复核记录保存在本地 `validation/` 目录，包含账号信息，不随源码公开。最终仍不能确认普通免费账号每日必然能完成两条15秒或三条7秒。
